# Esquina do Espeto - Cardápio digital

Cardápio estático (HTML, CSS e JavaScript puros) para GitHub Pages.

- `index.html` - página
- `styles.css` - visual
- `data.js` - **cardápio (nomes, preços e descrições): edite aqui**
- `app.js` - navegação, busca, sacola e envio do pedido
- `logo-web.svg` - logo otimizado; `logo.png`, `icon.png` (favicon) e `miniatura.png` (compartilhamento) são os originais

Publicado em: https://vitrine-show.github.io/menu-bot/
